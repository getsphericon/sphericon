# Frontend architecture

- The README mentions oRPC, but the site client is
  actually the generated `@hey-api/openapi-ts` fetch client + react-query hooks in
  `src/generated/site/` (consume these, don't hand-write fetch calls).
- Routing is TanStack Router **file-based**: `src/routes/` holds only thin route files. `foo.tsx` has the
  guards and search schemas and never imports a page; the page component is bound in the sibling
  `foo.lazy.tsx` (`createLazyFileRoute`). That keeps `import/no-cycle` clean (a page imports its
  route's `Route`, the route never imports the page) and lets Fast Refresh update a page instead of
  reloading the tab. The pages themselves live in
  `src/pages/`, and `src/router.ts` builds the router with the `QueryClient` in its context. A page
  reaches its route (`to`, `useParams`, `useSearch`) through the route file's `Route` export; never
  rebuild the tree by hand. Route guards read the workspaces list through `requireWorkspaces`
  (`src/guards.ts`, the shared query cache) and redirect to `/login` on 401. Tests mount a page with
  `renderWithRouter(ui, routeMount(Route, params))`, which mirrors the route's ancestry.
- Layers are checked by easement (`easement.yml`, `mise run check:arch`): `src/components`, `hooks`,
  `layouts`, `resources` and `utils` never import a page; a page never imports a `*.lazy.tsx`;
  only `*.lazy.tsx` route files import a page; a feature directory under `src/pages` never imports
  another feature's (what two features share, such as the Condition builder, lives in
  `src/components`); `src/generated` imports nothing of ours. Something a route's search schema
  needs lives in `src/utils`, not next to its page. Every file under `src/` must belong to a
  component (`strict`), so a new top-level directory is added to `easement.yml`.
- A library comes before a hand-written helper: `@mantine/hooks` and `ahooks` for hooks, `es-toolkit`
  for utilities, `@mantine/charts` for charts, dates through `src/utils/datetime.ts` (dayjs, which
  `easement.yml` refuses elsewhere; feeds show `<RelativeTime>`).
- Load states: a component reads its data with `useSuspenseQuery` under a `QueryBoundary`
  (`src/components/QueryBoundary.tsx`), which shows the skeleton, the error and a retry. A plain
  `useQuery` is for a query behind `enabled`, one driven by typed input (`keepPreviousData`) and a
  permission probe. A detail route loads its record with `preload` (`src/utils/preload.ts`).
- A paged list's page is its route's `page` search param: the route validates `pagedSearch`, or
  `archivableSearch` for a list with an archived view (`src/searchSchemas.ts`). The page reads it and
  hands `PagedTable` the page and a `withPage` navigation. A form a person can leave half-typed
  renders `LeaveDialog`.
- A dependency a test can reach is listed in `optimizeDeps.include` (`vite.config.ts`), a tracker
  one as `@sphericon/analytics > <pkg>`: found mid-run, Vite reloads the browser and fails tests.
- Toasts go through `useNotify()` (`src/hooks/useNotify.ts`), never Mantine's global `notifications`
  (lint refuses it): a `NotificationsProvider` owns one store per mount, and `renderWithProviders`
  mounts its own, so no test needs to clean toasts up. `renderWithProviders` also sets Mantine
  `env="test"` (no transitions or portals), which makes the suite ~40% faster and its timeouts less
  likely under load.
- i18n via i18next; `locales/`, types generated by `mise run generate:i18n-types`. The app runs on
  its own instance (`src/i18n.ts`), reached through `useTranslation`; the global `i18next` belongs to
  the workflow builder SDK and is used only in `AutomationBuilder.tsx` (`easement.yml` refuses it).
  **English is the only locale.** There are no `ru`/`es` (or any other) catalogs, in `locales/` or in
  `internal/i18n/locales/`: a new string gets its `en` entry and nothing else, and no Russian or other
  non-English text goes into the repo. A key no code reads fails `check:i18n` and `mise run fix`
  deletes it; a key looked up by a value from the API (`$.rules.firingStatus[status]`) is invisible
  to the extractor, so its family goes into `preservePatterns` in `i18next.config.ts`.
- Lint is **oxlint** (all plugins, type-aware via oxlint-tsgolint; `oxlint.config.ts`) and format is **oxfmt** (`oxfmt.config.ts`; also formats Markdown/YAML/JSON). Single quotes, no semicolons, generated dirs ignored. Never disable a lint rule (`CODING_STANDARDS.md`).
- Unused deps/files/exports are caught by **knip** (`knip.ts`); secrets by **gitleaks** (`.gitleaks.toml`); workflows by **jactionlint** + **zizmor**; Go vulns by **govulncheck** (`mise run check:vulns`, nightly).
  Type-check is **tsc** (TypeScript 7, the native compiler).
